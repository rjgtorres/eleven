* Eleven

Eleven is a Common Lisp implementation of the card game played with a double deck.  
The project currently has complete domain modeling and broad test coverage, while some interactive gameplay pieces are still in progress.

** Rules

Implemented rule model:
- two decks of cards
- each player starts with 11 cards in hand
- 2 to 6 players
- round goals:
| trio | sequence |
|------+----------|
| 2    | 0        |
| 1    | 1        |
| 0    | 2        |
| 3    | 0        |
| 2    | 1        |
| 1    | 2        |
| 0    | 3        |
- a trio is three cards with the same face (with joker restrictions)
- a sequence is 4+ consecutive cards in the same suite (with joker and ace rules)

Turn flow currently modeled:
- draw phase: the active player starts by taking a card from the deck or discard pile, then the other players get a chance to draw from the discard pile before play continues
- lay-down phase: if the player has completed the round goal, they can place the cards that satisfy it onto their board
- add-to-goals phase: after laying down, the player can try to attach cards from hand to existing trios or sequences on any board
- discard phase: the turn ends by discarding one card from hand

Round structure:
- each round uses a specific trio/sequence goal combination from the table above
- when a player empties their hand, the round ends and points are counted
- the next round starts with the next player in rotation
